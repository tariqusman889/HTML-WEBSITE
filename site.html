1CSS Basics

CSS teen tarike se lagai ja sakti hai: Inline (tag ke andar style="..."), Internal (head mein <style> tag), aur External (alag .css file link karna). External sab se best hai kyun ke code clean rehta hai. 
<!-- 1. Inline CSS -->
<p style="color: blue;">Ye inline hai</p>

<!-- 2. Internal CSS -->
<head>
  <style>
    p { color: green; }
  </style>
</head>

<!-- 3. External CSS -->
<head>
  <link rel="stylesheet" href="style.css">
</head>

2Selectors

Selector batata hai ke CSS kis element pe lagni hai. Class ke liye dot (.) aur ID ke liye hash (#) use hota hai. Pseudo-class jaise :hover use hota hai jab mouse element pe jaye. 
/* Element selector */
p { color: black; }

/* Class selector */
.highlight { background: yellow; }

/* ID selector */
#header { font-size: 24px; }

/* Pseudo-class */
button:hover { background: red; }

/* Child combinator */
div > p { margin: 0; }

/* nth-child */
li:nth-child(2) { color: blue; }

3Box Model

Har HTML element ek box hota hai jisme 4 layers hoti hain: Content → Padding → Border → Margin. box-sizing: border-box lagane se width/height mein padding aur border khud shamil ho jate hain, calculation asaan ho jati hai.
Content
* {
  box-sizing: border-box; /* IMPORTANT - hamesha lagayen */
}

.box {
  width: 200px;
  padding: 20px;      /* content ke around space */
  border: 8px solid blue;
  margin: 20px;        /* box ke bahar space */
  background: lightblue;
}

4Colors & Backgrounds

Colors ko hex (#ff0000), rgb, ya rgba (transparency ke sath) mein likh sakte hain. Background image, gradient, position sab control ho sakta hai.
Gradient Background
.box {
  background-color: #ff6b6b;
  background-image: linear-gradient(45deg, white, transparent);
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

/* rgba - a = alpha (transparency 0 se 1) */
.transparent-box {
  background-color: rgba(255, 0, 0, 0.5);
}

6Display Property

block = pori line leta hai (div, p). inline = sirf jitni jagah chahiye utni leta hai, width/height set nahi hoti (span, a). inline-block = dono ka mix, inline rehta hai lekin width/height set kar sakte hain.
Block Inline Inline-Block 
.block { display: block; width: 150px; }
.inline { display: inline; }         /* width kaam nahi karti */
.inline-block { display: inline-block; width: 100px; }
.hidden { display: none; }            /* element gayab, space bhi nahi leta */
.invisible { visibility: hidden; }    /* gayab lekin space rehta hai */

7Positioning

static = default. relative = apni original jagah se hat sakta hai. absolute = parent (jo relative ho) ke andar kahin bhi rakh sakte hain. fixed = screen pe hamesha same jagah rehta hai (scroll pe bhi). sticky = scroll tak normal, phir chipak jata hai.
Absolute Box
Parent (position: relative) 
.parent {
  position: relative; /* zaroori hai taake child isi ke andar position ho */
}

.child {
  position: absolute;
  top: 10px;
  right: 10px;
}

.navbar {
  position: fixed;
  top: 0;
  width: 100%;
  z-index: 100; /* upar dikhane ke liye */
}

8Flexbox (Sab se Zaroori Topic)

Flexbox items ko ek row ya column mein arrange karta hai. justify-content horizontal alignment control karta hai, align-items vertical alignment. Ye modern layouts ke liye must hai.
Box 1
Box 2
Box 3
.container {
  display: flex;
  justify-content: space-around; /* horizontal spacing */
  align-items: center;            /* vertical alignment */
  flex-direction: row;            /* row ya column */
  flex-wrap: wrap;                /* chote screen pe wrap ho */
  gap: 10px;                      /* items ke darmiyan gap */
}

.item {
  flex: 1; /* barabar space le */
}

9CSS Grid

Grid rows aur columns dono ek sath control karta hai. 2D layouts (jaise pura page layout) ke liye Grid best hai, jabke Flexbox 1D (row ya column) ke liye better hai.

10Responsive Design

Media queries se aap screen size ke hisab se alag CSS de sakte hain. Mobile-first approach mein pehle mobile ke liye CSS likhte hain, phir bare screens ke liye media query add karte hain. Neeche wala box screen ka size change karne pe rang badalta hai.
Browser window resize karke dekhein
/* Mobile-first: default chote screen ke liye */
.box {
  width: 100%;
  font-size: 14px;
}

/* Tablet aur bare screens ke liye */
@media (min-width: 601px) {
  .box {
    width: 50%;
    font-size: 18px;
  }
}

/* Units: rem (root se relative), em (parent se relative),
   vw/vh (viewport width/height ka %) */
.text {
  font-size: 2rem;
  width: 50vw;
}

11Transitions & Animations

Transition smooth change deta hai jab koi property badle (jaise hover pe). Animation with @keyframes automatic, repeating animation banata hai bina kisi trigger ke.

Hover karein 👇

Auto animation 👇

/* Transition - hover pe smooth change */
.box {
  background: blue;
  transition: all 0.4s ease-in-out;
}
.box:hover {
  background: red;
  transform: scale(1.3) rotate(10deg);
}

/* Animation - automatic loop */
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}
.ball {
  animation: bounce 1s infinite ease-in-out;
}

12CSS Variables & Shadows

CSS Variables (--name) se aap ek color/value ek jagah define karke pure project mein reuse kar sakte hain — change karna easy ho jata hai. Shadows se depth aur professional look milta hai.
Yeh box CSS Variables aur Shadow use karta hai
:root {
  --main-color: #4b6cb7;
  --shadow-color: rgba(0,0,0,0.3);
}

.box {
  background: var(--main-color);
  box-shadow: 0 6px 15px var(--shadow-color);
}

.text-shadow-demo {
  text-shadow: 2px 2px 4px gray;
}

.scroll-box {
  overflow: auto; /* scroll: hidden, scroll, auto */
}
